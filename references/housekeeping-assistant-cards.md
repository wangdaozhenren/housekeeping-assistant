## L1 常识卡（11 张）

### [L1] 日常保洁和深度保洁有什么区别

- **一句话结论**：日常保洁是表面打扫（扫地擦灰、整理），深度保洁针对油污/水垢/死角和厨卫重污，价格和耗时都更高。
- **依据/来源**：家政行业通用服务分级经验。
- **边界声明**：因城市/平台标准而异。
- **最后核验**：2026-09。

### [L1] 按次、按小时、按平米分别是什么意思

- **一句话结论**：按次是一口价包干（如深度保洁 199 元/次），按小时是计时（如 50 元/小时起），按平米是按面积（如开荒 8 元/平米），三种口径要换算成总价才能比。
- **依据/来源**：knowledge.md 计价口径。
- **边界声明**：—
- **最后核验**：2026-09。

### [L1] 开荒保洁是什么

- **一句话结论**：新房/装修后第一次彻底打扫（除胶、除漆点、擦窗、除水泥点），通常按平米计价，比普通保洁贵。
- **依据/来源**：家政行业通用服务项目。
- **边界声明**：因房屋状况而异。
- **最后核验**：2026-09。

### [L1] 家电清洗都洗什么

- **一句话结论**：油烟机、空调、洗衣机、热水器等拆机清洗，按台数和机型收费，不同机型价差大；要确认是否含拆机和安装复位。
- **依据/来源**：家政/家电清洗行业通用项目。

### [L4] 下单前需求清单四步

- **一句话结论**：把"做什么、多大、几层、特殊情况"一次写清，锁定报价防加价。
- **步骤**：
  1. **定项目**：日常保洁/深度保洁/开荒/家电清洗，明确要做哪几项；
  2. **定面积口径**：报套内还是建筑面积，写进需求；
  3. **定特殊项**：楼层高不高、要不要擦外窗、油污重不重、节假日；
  4. **要书面确认**：下单后让客服复述最终一口价，截图留存。
- **常见错误**：只说"来做个保洁"，上门后范围不清被加项。
- **适用边界**：经验属性，非官方标准。
- **标注**：经验属性，非官方标准。
- **最后核验**：2026-09。

### [L4] 上门前准备三步

- **一句话结论**：提前收拾贵重物品和小件，服务更高效也防纠纷。
- **步骤**：
  1. **收好贵重/易碎品**：首饰、证件、贵重摆件单独收；
  2. **提前归位小件**：衣服、杂物先收，师傅专注打扫地面台面；
  3. **留好通道和水电**：确认水电正常、门口可进出。
- **常见错误**：东西乱堆导致师傅按"工作量大"要求加时加价。
- **适用边界**：经验属性，非官方标准。
- **标注**：经验属性，非官方标准。

### [L4] 服务中验收要点

- **一句话结论**：服务完当场验收，重点看厨卫死角、玻璃、地面，有问题当场提出。
- **步骤**：
  1. **看重点区域**：厨房油污、卫生间水垢、地面边角；
  2. **核对时长/项目**：是否做了下单时约定的每一项；
  3. **当场提问题**：不满意当场要求返工，别等师傅走了再说；
  4. **确认无遗漏损坏**：检查物品有无损坏、工具是否带齐。
- **常见错误**：师傅走后才发现没洗干净，平台维权困难。

### [L4] 家电清洗预约时机

- **一句话结论**：油烟机春节前、空调入夏前、洗衣机换季时是旺季，提前 1~2 周约更便宜更好约。
- **步骤**：
  1. **看季节**：空调 4~5 月约、油烟机腊月前约；
  2. **错峰**：避开周末和节假日高价档；
  3. **看状态**：出风有异味/排水慢就安排，不等坏了再修；
  4. **留凭证**：保留清洗记录和保修期。
- **常见错误**：旺季临时约只能接受节假日加价。
- **适用边界**：经验属性，非官方标准。

### [L4] 长期包月/次卡算账法

- **一句话结论**：买次卡/月卡前先按"一年实际会用几次"算清，别为便宜买了用不完。
- **步骤**：
  1. **估频率**：过去半年实际叫了几次；
  2. **算次卡总价**：次卡单价×预计次数，和零买价比；
  3. **看有效期**：过期作废算不算、能否转他人；
  4. **小额试水**：先买少量次数体验，满意再续。
- **常见错误**：图折扣买一大张卡，搬家/换工作后作废。
- **适用边界**：经验属性，非官方标准。

### [L4] 纠纷维权取证流程

- **一句话结论**：出问题先固定证据再找平台，别只口头吵。
- **步骤**：
  1. **留证据**：订单截图、服务清单、损坏物品照片/视频；
  2. **找平台**：在订单页申请售后/投诉，附证据；
  3. **要求明确方案**：返工、赔偿或退款，要书面回复；
  4. **升级**：平台不处理可拨打 12315 或向消协反映。
- **常见错误**：师傅走了没留证据，平台无法判定。
- **适用边界**：信息参考，不构成法律意见。
- **标注**：经验属性，非官方标准。
